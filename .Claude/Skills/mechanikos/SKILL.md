# Mechanikos — Βοηθός Μηχανικού

Skill για ερωτήσεις που αφορούν τεχνικά μηχανικών, κτηματολόγιο, όρους δόμησης, και νομοθεσία κατασκευών.

## Πότε ενεργοποιείται

- Ο χρήστης ρωτά για **KAEK**, κτηματολόγιο, τεμάχιο
- Ο χρήστης ρωτά για **όρους δόμησης** (κάλυψη, συντελεστής δόμησης, ύψος, όροφοι)
- Ο χρήστης ρωτά για **νόμους** (ΝΟΚ, Ν.4067, Ν.4495, ΚΕΝΑΚ, ΓΟΚ, Κτιριοδομικός)
- Ο χρήστης ρωτά για **οικοδομική άδεια**, αυθαίρετα, τακτοποίηση
- Λέξεις-κλειδιά: κάλυψη, ΣΔ, δόμηση, πολεοδομία, KAEK, κτηματολόγιο, μηχανικός

## MCP Tools (mechanikos server)

| Tool | Τι κάνει |
|------|----------|
| `mcp__mechanikos__lookup_kaek` | Αναζήτηση τεμαχίου με KAEK (12 ψηφία) → γεωμετρία, εμβαδόν |
| `mcp__mechanikos__parcels_by_coordinates` | Εύρεση τεμαχίων σε lat/lon → λίστα KAEK |
| `mcp__mechanikos__search_legislation` | Αναζήτηση στη νομοθεσία δόμησης με keyword |
| `mcp__mechanikos__get_article` | Πλήρες κείμενο άρθρου νόμου (π.χ. ΝΟΚ Άρθρο 11) |
| `mcp__mechanikos__building_terms_by_kaek` | Όροι δόμησης για KAEK (κάλυψη, ΣΔ, ύψος) |

## Ροή εργασίας

### 1. Ερώτηση για KAEK / τεμάχιο

```
Χρήστης: "Τι ισχύει για το KAEK 050460313012;"
→ mcp__mechanikos__lookup_kaek(kaek="050460313012")
→ mcp__mechanikos__building_terms_by_kaek(kaek="050460313012")
→ Παρουσίαση: εμβαδόν + όροι δόμησης + σχετικά άρθρα ΝΟΚ
```

### 2. Ερώτηση για νομοθεσία

```
Χρήστης: "Τι λέει ο ΝΟΚ για τον συντελεστή δόμησης;"
→ mcp__mechanikos__search_legislation(keyword="συντελεστής δόμησης", laws="ΝΟΚ")
→ mcp__mechanikos__get_article(law="ΝΟΚ", article_number="11")
→ Παρουσίαση: πλήρες κείμενο Άρθρου 11 + ερμηνεία
```

### 3. Ερώτηση με συντεταγμένες

```
Χρήστης: "Ποια τεμάχια υπάρχουν στις συντεταγμένες 36.44, 28.22;"
→ mcp__mechanikos__parcels_by_coordinates(lat=36.44, lon=28.22)
→ Παρουσίαση: λίστα KAEK + εμβαδά
```

|-------|------|-------------|
| **ΝΟΚ (Ν.4067/2012)** | Οικοδομικός Κώδικας | Άρθρα 6-20: άδεια, κάλυψη, ΣΔ, ύψος, θέση κτιρίου |
| **Ν.4495/2017** | Αυθαίρετα, πολεοδομία | Τακτοποίηση, ηλεκτρονική ταυτότητα κτιρίου |
